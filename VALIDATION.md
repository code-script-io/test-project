## Limits

The browser suite uses a `?test=1` bridge to position actors and teleport between checkpoints. It runs the real collision, input, AI, weapon and progression implementations; it is not a manual uninterrupted playthrough. AI time is advanced deterministically for the attack check. Unit tests do not test graphical fidelity. Web Audio startup is checked by its context state; sound quality has not been auditioned by a human tester.

Android touch is emulated in desktop Chromium. No physical Android device, Windows installation, Firefox or Safari was tested. Hardware frame rate and battery consumption remain device-dependent. Low graphics limits active lights, resolution and shadows for less powerful devices.

Vite reports a nonfatal bundle-size warning because the game and Three.js are bundled together (approximately 562 kB minified, 149 kB gzip). The game has no external runtime asset or service requests. A new-task cloud snapshot and environment publication were not performed as part of game development.

The README describes the compact game's scope, including low-obstacle vaulting, procedural art and local-only checkpoints.
